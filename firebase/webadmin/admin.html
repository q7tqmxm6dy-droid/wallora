Wallpapers in the app

Built into the Android app (and the website where marked). A wallpaper with a light and a dark version is drawn as one split picture: light on the left, dark on the right. Click one to preview Split, Day or Night. They come from the app's code, so they can't be edited or deleted here. Use Upload wallpaper below to add new ones without an app update.

Upload wallpaper

Every wallpaper needs one image. Add a second one to make it a light + dark pair: the app then shows the dark version at night and the light version by day, and draws the pair as one split picture. Leave the dark version empty for a single-image wallpaper (for example deep space).

Add by image URL

Host the image anywhere public and paste the link — no Cloud Storage needed. Add a dark version URL to make a light + dark pair. (Cloud Storage for Firebase now requires the Blaze plan on new projects.)
